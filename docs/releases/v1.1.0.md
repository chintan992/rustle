# Rustle 1.1.0 — Announcements

Rustle 1.1.0 adds optional announcement notifications so you can keep up with
Rustle news and updates.

- New installs are asked after voice setup whether to enable announcement
  notifications.
- Android notification permission is requested only after the user chooses
  **Enable notifications**. Notifications remain optional and can be changed
  in Settings.
- Announcement messages open Rustle when tapped.
- Existing installs keep their saved notification preference.

Requires Android 7.0 (API 24) or later. Notification delivery requires an
internet connection and an opted-in device. Android may delay or suppress
notifications according to device settings and power management.

Choose the APK matching your device ABI. The in-app updater uses the
`rustle-update.json` file attached to this release.
