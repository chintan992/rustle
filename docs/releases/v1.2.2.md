# Rustle 1.2.2 — Play Store Compatible

Rustle 1.2.2 republishes the Play-compatible distribution with a new Android
version code (`6`) so it can be uploaded after version code `4` was already
used.

- The Play App Bundle omits `REQUEST_INSTALL_PACKAGES`, the GitHub updater
  provider, and GitHub updater controls. Play-installed builds update through
  Google Play.
- GitHub APK builds retain the in-app GitHub updater and its install flow.
- Guided first-run setup remains unchanged.

Upload `Rustle-Play-1.2.2.aab` to Play Console. Do not upload a GitHub APK.

Requires Android 7.0 (API 24) or later. Voice model downloads require an
internet connection and about 138 MB of storage. Narration works offline after
the pack is installed.
