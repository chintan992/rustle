# Rustle 1.2.1 — Play Store Compatible

Rustle 1.2.1 adds separate distribution variants:

- The Play Store App Bundle omits `REQUEST_INSTALL_PACKAGES`, the GitHub
  updater provider, and GitHub updater controls. Play-installed builds update
  through Google Play.
- GitHub APK builds retain the in-app GitHub updater and its install flow.
- Both variants include the guided first-run notification, model setup, and
  default narrator flow introduced in 1.2.0.

The Play upload is built as the `playRelease` variant. GitHub APKs are built as
the `githubRelease` variant. The GitHub APKs intentionally retain the
`REQUEST_INSTALL_PACKAGES` permission for their self-updater; only
`app-play-release.aab` is the Play-compatible artifact. Do not upload a GitHub
APK to Play Console.

Requires Android 7.0 (API 24) or later. Voice model downloads require an
internet connection and about 138 MB of storage. Narration works offline after
the pack is installed.
