# Rustle 1.2.2 — Play Store release

**Version name:** `1.2.2`

**Version code:** `6`

**What's new:**

- Separate Play Store build with Google Play-managed updates.
- The Play build does not request permission to install packages.
- Guided first-run setup for notification choice, speech model download and
  initialization, and default narrator selection.

## Upload

Upload `Rustle-Play-1.2.2.aab` from the
[v1.2.2 GitHub release](https://github.com/chintan992/rustle/releases/tag/v1.2.2).
This bundle uses version code 6 and excludes the `REQUEST_INSTALL_PACKAGES`
permission. Do not upload any of the GitHub APKs to Play Console.

Keep the public privacy policy URL configured:
<https://chintan992.github.io/rustle/privacy-policy/>

Complete or verify the Data safety, content-rating, target-audience, and
app-access declarations in Play Console before submission.
